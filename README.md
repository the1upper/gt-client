# Golden Thugget Client

The player addon for The Golden Thugget (WoW Forever). If you weren't sent here by the house, this isn't for you.

## Install with WowUp (auto-updates)
1. Open WowUp and pick your **WoW Forever** install at the top.
2. Go to **Get Addons**, then **Install from URL**.
3. Paste this repository's address and install.
4. In game, at character select, open **AddOns** and make sure **Golden Thugget Client** is ticked.

WowUp will show new versions under **My Addons** like any other addon.

## Install by hand
Download the latest `TheGoldenThugget_Client-x.y.z-forever.zip` from **Releases** and unzip it into
`World of Warcraft/_forever_/Interface/AddOns/`.

How to play: type `/gt` in game, or read `TheGoldenThugget_Client/README.md`.
